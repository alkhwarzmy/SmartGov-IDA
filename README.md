# SmartGov-IDA — أرشيف محلي ذكي

MVP لأرشفة PDF وPNG وJPEG، مع حفظ الأصل ببصمة SHA-256، وقراءة النص الرقمي أو OCR محلي، وتصنيف خطاب/فاتورة/غير معروف، واستخراج حقول بالقواعد، ومراجعة وتصحيح وبحث نصي محلي.

**المراجعة البشرية إلزامية.** OCR مساعد غير معتمد للدقة التلقائية؛ مقارنة PaddleOCR مؤجلة بسبب حجب الأوزان. التطبيق ليس نظامًا حكوميًا إنتاجيًا. التفاصيل والأخطاء المقاسة موثقة في [تقرير التسليم](docs/delivery.md)، بما فيها فشل الاستخراج في الاختبار الأول وإصلاحه وفحصه التشخيصي.

## التشغيل في بيئة المشروع

Python 3.12 على Linux x86_64. التجهيز الأولي يحتاج الإنترنت لتنزيل الاعتماديات والأوزان المثبتة، ثم تعمل دورة الاستخدام محليًا:

```bash
cd /workspace/SmartGov-IDA
sh scripts/setup_dev.sh
/workspace/smartgov-venv/bin/python -m archive_system.cli --data-dir /workspace/smartgov-data --model-dir /workspace/smartgov-models/tesseract serve
```

افتح العنوان المحلي الذي يطبعه الأمر، بالمنفذ 8765. لا يرتبط التطبيق بواجهة عامة، ولا تُستخدم أصول CDN أو خدمات OCR خارجية. عامل معالجة واحد ومستخدم واحد. الحدود الافتراضية 10 صفحات و20 MiB، ويمكن ضبطها بمتغيرات البيئة الموضحة في الدليل التقني.

## التحقق

```bash
/workspace/smartgov-venv/bin/python -m pytest -q
/workspace/smartgov-venv/bin/python scripts/verify_offline_reading.py
```

النتيجة الموثقة: **70 اختبارًا ناجحًا** دون إخفاق أو تخطي، وفحص متصفح لمسار الرفع والتصحيح والتأكيد والبحث والتنزيل ومعاينة الأصل والعرض الضيق، وتثبيت جديد من حزمة wheels دون شبكة مع نجاح النسخ والاستعادة. الاختبارات الاصطناعية لا تثبت دقة واقعية؛ تقارير كل فحص في `evaluation/results/`.

## حزمة تثبيت دون إنترنت

```bash
/workspace/smartgov-venv/bin/python scripts/build_offline_bundle.py --output /workspace/smartgov-delivery/new-bundle
```

اختر مجلدًا جديدًا. الحزمة تشمل التطبيق وwheels مثبتة الإصدار والبصمة وأوزان ara+eng والأمثلة والإشعارات. بعد نقلها إلى جهاز مناسب مجهز مسبقًا بـ Python 3.12 وvenv/ensurepip، نفذ `sh install.sh /absolute/path/to/new-venv`؛ لا تحتاج الحزمة اتصالًا عند التثبيت أو التشغيل. استهداف الحزمة Linux x86_64 فقط، ولا تشمل Python أو نظام التشغيل.

الأوزان والوثائق التشغيلية وقاعدة البيانات والحزم الثنائية **خارج Git**. المستودع يحتوي الكود والاختبارات والبيانات النصية الاصطناعية الصغيرة والتوثيق وأدوات إعادة إنتاج الحزمة. الحزمة للاستخدام المحلي الداخلي؛ مراجعة التزامات إعادة التوزيع موثقة، ومنها libjbig المضمن تحت GPL-2-or-later. ترخيص كود المشروع يقرره مالك المستودع قبل نشر خارجي.
