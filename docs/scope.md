# نطاق المرحلة الأولى

نسخة MVP لمستخدم محلي واحد، مستند واحد في المعالجة. المدخلات المستهدفة PDF وPNG وJPEG بحد 10 صفحات و20 MiB (20,971,520 بايت) قابل للتغيير في Settings. PDF متعدد الصفحات؛ الصور مفردة الصفحة في النطاق الأولي. النص مطبوع بالعربية، ومعه الإنجليزية والأرقام. التشغيل الكامل المستهدف محلي دون خدمات أو أصول خارجية أو تنزيل أوزان عند البدء.

الخطاب: letter_number، date، sender، recipient، subject.
الفاتورة: invoice_number، date، supplier، total، currency.
غير المعروف: unknown، لا حقول مفترضة. كل حقل مدعوم مطلوب للمراجعة؛ غيابه لا يعني رفض حفظ الأصل.

الحالات: missing غياب، ambiguous عدة احتمالات، invalid صيغة غير صالحة، needs_review نص غير مقروء أو شك، valid اجتاز تحقق القواعد فقط ولا يضمن صحة واقعية.

خارج النطاق: اليدوي، فهم الجداول والأختام والتوقيعات، النشر الحكومي، تعدد المستخدمين، البحث الدلالي، التدريب، المعالجة الكبيرة. حماية الجهاز والنسخ الاحتياطي لازمة؛ هذه ليست جاهزية إنتاجية مؤسسية.

البنية المستهدفة Modular Monolith: إدخال ← قراءة PDF أو OCR ← تصنيف بالقواعد ← استخراج وتحقق ← SQLite/FTS5 وأصول منفصلة ← API وواجهة عربية محلية ومراجعات مستقلة. لن تُنشأ وحدات فارغة قبل الحاجة إليها.

عينة البداية 16 مستندًا اصطناعيًا نصيًا، 16 صفحة منطقية، دون بيانات شخصية: 6 خطابات و6 فواتير و4 غير معروف. التطوير 8 والاختبار 8؛ تختلف عائلات التنسيق ولا تتكرر البصمات بينهما. كلاهما مؤلف اصطناعي واحد؛ الفصل ليس فصل مصادر واقعية مستقلًا. تتضمن الغياب والالتباس وغير المقروء. الصور وPDF المشتقة ستجهز في المرحلة الثانية مع بقاء المستند وعائلته ضمن قسم واحد. سقف جمع البيانات 500 MiB و200 صفحة؛ أي توسع يسجل سببه قبل التنفيذ.

لا تُضبط القواعد على قسم test؛ manifest يثبت بصمات نصوصه. أي تغيير في المرجع يحتاج إصدارًا جديدًا وتوثيقًا قبل التقييم. البيانات الاصطناعية محدودة القوالب لا تثبت الدقة الواقعية.
