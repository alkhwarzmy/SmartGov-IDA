# دليل المستخدم

هذا تطبيق محلي أولي لمستخدم واحد على Linux. يدعم خطابًا إداريًا وفاتورة مطبوعة، ويحتفظ بغير المعروف دون اختلاق حقول. الحدود الافتراضية 10 صفحات و20 MiB، وتُرفض الكتابة اليدوية والجداول المعقدة كقدرات فهم تلقائي.

## بدء التطبيق

من بيئة التطوير المجهزة:

```bash
cd /workspace/SmartGov-IDA
/workspace/smartgov-venv/bin/python -m archive_system.cli --data-dir /workspace/smartgov-data --model-dir /workspace/smartgov-models/tesseract serve
```

افتح عنوان الجهاز المحلي الذي يطبعه الأمر، بالمنفذ 8765. التطبيق يرتبط بواجهة loopback فقط ولا ينشر خدمة خارجية. يحتفظ التشغيل بعملية معالجة واحدة. أوقف الأمر بـ Ctrl+C بعد الانتهاء. لا تفتح العملية نفسها مرتين على مجلد البيانات نفسه.

للحزمة المنفصلة: استخرجها، ثم نفذ `sh install.sh /absolute/path/to/new-venv`، واستخدم Python الموجود في تلك البيئة ومسار `models/tesseract` داخل الحزمة. يلزم Python 3.12 وvenv/ensurepip مثبتان مسبقًا. لا يلزم إنترنت بعد تجهيز هذه المتطلبات.

## دورة الأرشفة

1. اختر PDF أو PNG أو JPEG واضغط «رفع ومعالجة». يحفظ الأصل كما هو، ثم يحاول استخراج النص والحقول. الملفات المتكررة تفتح السجل الموجود دون إعادة المعالجة. الأصل التالف أو المشفر الذي قُبلت صيغته يبقى محفوظًا مع حالة فشل واضحة.
2. قارن المعاينة مع النص. لصفحات OCR، صحح النص كاملًا ثم اضغط «حفظ النص ومراجعته» حتى إن لم تحتج لتغيير. هذه خطوة لازمة قبل الاعتماد. يمكنك اختيار صفحة المعاينة في PDF متعدد الصفحات، وفتح الأصل أو تنزيله.
3. تحقق من التصنيف. إن صححته، تعرض حقول النوع الجديد، وتبقى نتيجة التصنيف الأولى في السجل.
4. صحح كل حقل واضغط «حفظ الحقل». التاريخ ذو الشكل YYYY-MM-DD لا يحدد التقويم تلقائيًا؛ اختر ميلاديًا فقط عندما تتأكد من الأصل. التواريخ الهجرية تحفظ دون تحويل وتبقى بحاجة تحقق تقويمي في هذه النسخة. القيم الملتبسة لا تُحسم آليًا.
5. إن كان الحقل غائبًا من الأصل فعلًا، اترك القيمة فارغة وأضف ملاحظة مثل «غائب من الأصل»، ثم احفظه. لا تستخدم ذلك لتجاوز قيمة غير مقروءة؛ احتفظ بها للمراجعة.
6. إذا عدلت نص الصفحة، أعد مراجعة وحفظ حقول المستند بعد آخر تعديل. لا يكتب تعديل النص فوق النص الأول ولا يعيد استخراج حقول جديدة تلقائيًا.
7. علّم مربع الإقرار بالمراجعة ثم اضغط «تأكيد اكتمال المراجعة». يرفض التطبيق الاعتماد ما دام النص فارغًا أو صفحة OCR غير مراجعة أو الحقول غير محسومة. «مكتمل المراجعة» يعني تأكيد المستخدم، وليس ضمان صحة آلية.

الخطاب: رقم الخطاب والتاريخ والمرسل والمستقبل والموضوع. الفاتورة: رقم الفاتورة والتاريخ والمورد والإجمالي والعملة. الاستخراج الأفضل لحقول ذات تسميات واضحة وفواصل؛ النص الذي فقد فاصلًا قد يظهر كمرشح يحتاج مراجعة. القيم مثل الأختام والتواقيع والجداول لا يفهمها النظام عمومًا.

## البحث والسجل

ابحث بكلمة من المتن، أو رقم مستند، أو قيمة مصححة. تشمل الفهرسة النص الفعال للصفحات والقيم الفعالة للحقول. النص الأصلي يبقى في سجل المحاولات. فلاتر النوع والحالة والتاريخ متاحة؛ فلتر التاريخ يخص تاريخ المستند الميلادي المتحقق فقط، لا تاريخ الرفع، ولا يخلط تقاويم مختلفة.

البحث نصي محلي: توحيد محدود للأرقام والتشكيل والمسافات، دون اشتقاق عربي أو بحث دلالي. كلمات البحث عبارات حرفية؛ لا تحتاج كتابة صيغة FTS. النتائج مقسمة إلى صفحات.

يمكن عرض نتائج كل محاولة من سجل المعالجة. «إعادة المعالجة» تضيف محاولة جديدة وتعيد حالة المراجعة؛ لا تحذف المحاولات أو التصحيحات السابقة. التصحيحات مرتبطة بمحاولتها ولا تُنقل بصمت إلى محاولة جديدة.

## النسخ والاستعادة

أوقف التطبيق قبل استخدام أوامر CLI التالية على مجلد بياناته؛ العملية الواحدة تقفل المجلد لمنع تشغيل ثانٍ. اختر اسم نسخة جديدًا ومجلد استعادة غير موجود، لتجنب استبدال عمل سابق:

```bash
/workspace/smartgov-venv/bin/python -m archive_system.cli --data-dir /workspace/smartgov-data --model-dir /workspace/smartgov-models/tesseract backup /workspace/smartgov-backups/archive-001.zip
/workspace/smartgov-venv/bin/python -m archive_system.cli restore /workspace/smartgov-backups/archive-001.zip /workspace/smartgov-restored
/workspace/smartgov-venv/bin/python -m archive_system.cli --data-dir /workspace/smartgov-restored --model-dir /workspace/smartgov-models/tesseract serve
```

تحتوي النسخة على قاعدة البيانات والأصول المرتبطة وبصماتها، بما يشمل النصوص والحقول والمراجعات. الأوزان واعتماديات Python جزء من حزمة التشغيل المنفصلة. الاستعادة تفحص البصمات وتكامل SQLite والعلاقات ولا تستخرج مسارات عشوائية. احفظ النسخ على وسيط منفصل محمي واختبر استعادتها دوريًا. النسخ وقاعدة البيانات غير مشفرتين في هذه النسخة؛ حماية الجهاز والحساب والتخزين لازمة.

## أمثلة الحزمة

- `examples/letter.pdf`: خطاب اصطناعي رقمي، يحتاج تأكيد تقويم التاريخ والمراجعة.
- `examples/invoice.png`: صورة اصطناعية؛ راجع النص كاملًا والحقول، ولا تفترض صحة OCR.
- `examples/bad.pdf`: ملف اصطناعي غير صالح؛ يبقى الأصل محفوظًا وتظهر حالة فشل.

لم تستخدم وثائق حكومية أو شخصية حقيقية، ولم يرسل التطبيق محتوى مستندات إلى خدمات خارجية. هذه النسخة لا تشمل صلاحيات مؤسسية أو توقيعًا رقميًا أو سياسات احتفاظ وإتلاف نظامية.
