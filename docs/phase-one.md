# تقرير المرحلة الأولى

## المنجز

فُحص المستودع: فارغ بفرع work دون commits، ولا AGENTS.md. لم يستبدل أي عمل سابق. النطاق الافتراضي معتمد للتنفيذ: خطاب وفاتورة وغير معروف، مطبوع عربي، مستخدم وعامل معالجة واحد.

أضيفت عقود Pydantic للإعدادات والمستند والصفحة ومحاولة المعالجة والتصنيف والحقل ومصدره والمراجعة. أضيف دليل وسم وسجل تراخيص ومصدر اصطناعي ومراجع لستة عشر مستندًا نصيًا. التطوير 8 والاختبار 8، مع تجميد بصمات النصوص ووسوم الاختبار قبل تطوير القواعد. لا تُعامل المعرفات المختلفة وحدها كدليل استقلال؛ فُحص عدم تكرار النصوص وفصل عائلات التنسيق.

## التحقق الفعلي

الأمر: `/workspace/smartgov-venv/bin/python -m pytest -q` من جذر المستودع.
النتيجة النهائية: **13 passed in 0.13s**. تغطي سلامة العينة ومصادرها وحقولها ومقتطفاتها وسقفها وفصلها، تجميد وسوم الاختبار، منع تخمين الغائب، اشتراط المصدر، منع حسم الملتبس، حدود الإعدادات، منع نجاح محاولة ذات أخطاء، وفصل التصحيح عن نتيجة المحرك.

الاختبار الأول كشف تكرار عينات غير معروف بين القسمين؛ استبدلت بنصوص مختلفة قبل التجميد النهائي، وأعيدت الاختبارات بنجاح.

اختبار SQLite في الذاكرة نجح لإنشاء FTS5 وإدراج نص عربي واسترجاعه بواسطة MATCH. هذا يثبت توفر FTS5 فقط، وليس اكتمال فهرس التطبيق.

Python 3.12.14، Linux x86_64، خمس وحدات CPU منطقية، SQLite 3.53.1. تفاصيل الجهاز في evaluation/environment.json. العينة 16 صفحة منطقية و2,652 بايت من النصوص؛ لا تنزيل بيانات ولا أوزان. الإصدارات المثبتة محفوظة في requirements-dev.lock. البيئة الافتراضية خارج المستودع في /workspace/smartgov-venv.

## القيود وبوابة الانتقال

العينات نصية اصطناعية صغيرة، لا ملفات PDF/PNG/JPEG جاهزة ولا دليل على دقة واقعية. لم ينفذ OCR أو تصنيف أو استخراج أو تخزين أو API أو واجهة، ولم تقس CER/WER أو سرعة/ذاكرة OCR. تثبيت نظيف دون شبكة لم يختبر بعد. لم تنزل أوزان ولم تعتمد تراخيصها؛ سجل اعتماديات المرحلة الأولى منفصل عن ترخيص البيانات. لم ينشر المشروع أو يرسل محتوى إلى خدمة خارجية.

المرحلة الأولى جاهزة للمراجعة ضمن هذه الحدود. الانتقال إلى المرحلة الثانية يتطلب اعتماد المستخدم وفق طلبه الأخير. عند الاعتماد: تجهيز صور وPDF مرجعية من العائلات نفسها دون خلط الأقسام، مراجعة تراخيص المرشحين والأوزان العربية، مقارنة محركين فقط مع قياسات الجودة والزمن والذاكرة، ثم تحديد حدود القبول بناءً على القياس. لا يبدأ مكوّن تابع قبل اجتياز بوابته.
