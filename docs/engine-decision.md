# قرار تضييق النطاق قبل المراحل التابعة

طلب المستخدم متابعة بقية المراحل بعد تقرير جودة المرحلة الثانية. لم تتغير سياسة الشبكة المرصودة ولا أصبحت مقارنة Paddle ممكنة، ولا يجوز اعتبار Tesseract قد اجتاز بوابة الدقة.

النطاق المقبول للتنفيذ الآن: PDF ذي طبقة نص تجتاز فحوص القراءة، واستخراج حقول بالقواعد مع مراجعة بشرية قبل حالة «مكتمل». الصور وPDF المصور تحفظ أصولها، ويعرض Tesseract نصًا مساعدًا تجريبيًا يتطلب مراجعة النص الكامل والحقول. لا قبول تلقائي لنتيجة OCR، ولا تعميم لدقة واقعية. يستطيع المستخدم تصحيح نص الصفحة كاملًا وتأكيد مراجعته.

الاختبارات التابعة تثبت الحفظ والمراجعة والبحث والاسترجاع ضمن هذا النطاق، ولا تعتمد على افتراض نجاح OCR. تقييم OCR يبقى منفصلًا ويعرض أخطاءه. المقارنة الأصلية بين المحركين ومراجعة أوزان Paddle ما زالت مؤجلة بسبب الوصول؛ ليس هذا قرار تفضيل تجريبي لـTesseract على Paddle.

بوابة التنفيذ: اختبارات القراءة الناجحة وقيود الجودة المعلنة؛ بوابة الإكمال لكل مستند: مراجعة صريحة، نص غير فارغ، وحسم الحقول المطلوبة أو توثيق غيابها. الأصل ونتيجة المحرك لا يتغيران عند التصحيح. يختبر هذا القرار في مراحل الخدمة ثم الواجهة قبل تقييم الاختبار المجمد.
