# عقود البيانات v1

العقود في src/archive_system/domain/models.py، ترفض الحقول الزائدة وتستخدم معرفات UUID وأوقاتًا ذات منطقة زمنية.

Document يحفظ بيانات الأصل وبصمة SHA-256، ويمكن أن يكون عدد الصفحات غير معروف قبل القراءة. المسار مرجع تخزين داخلي وليس اسم الرفع المستخدم مباشرة.
Page مرتبط بالمستند والمحاولة؛ يحفظ النص ومصدره ومناطقه وثقته الاختيارية (0–1 لا احتمال صحة مضمون).
ProcessingRun مستقل لكل محاولة، يحفظ إصدار المحرك والنموذج وإعداداته والأزمنة ورموز الأخطاء دون نصوص حساسة. النجاح لا يقبل أخطاء؛ المحاولة النهائية تتطلب وقت انتهاء. تعاد المحاولة بمعرف جديد دون حذف السابقة.
Classification يحفظ الفئة وطريقة التصنيف وأسبابه؛ قواعد المرحلة الرابعة لا تمنح احتمالًا معايرًا افتراضيًا.
ExtractedField يحفظ الخام والتطبيع والمصادر وحالة التحقق والتقويم. missing يمنع القيم المفترضة، ambiguous يمنع حسم قيمة مطبعة.
Review سجل مستقل يستهدف حقلًا أو التصنيف، ولا يعدل نتيجة المحرك؛ null تصحيح يعني محو قيمة في العرض النهائي لا حذف التاريخ.

انتقالات التطبيق المستهدفة: received → processing → completed / needs_review / failed. الفشل يحفظ الأصل ويضيف محاولة مستقلة عند إعادة التشغيل. منطق الانتقالات وحدود الملفات والعلاقات بين المعرفات ووجود الملفات ستفرضها طبقة التطبيق والتخزين لاحقًا؛ نماذج Pydantic وحدها لا تثبتها.
التصحيحات append-only على مستوى التخزين المستقبلي؛ frozen يمنع إسناد خصائص النموذج لكنه ليس قيد قاعدة بيانات. البحث لاحقًا يشمل النص والقيم الفعالة مع الإبقاء على الأصل.
